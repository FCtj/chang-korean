# Chang Korean 🐘 (MVP v0.6)

라오스 사람들이 **그림(이모지)과 소리로** 한국어 단어를 외우는 앱입니다. (태국어는 다음 버전)
한 코드로 **안드로이드 앱**(Capacitor)과 **웹 버전**을 함께 만듭니다.

> 앱 이름 'Chang'은 라오어 ຊ້າງ / 태국어 ช้าง(코끼리)에서 따온 임시 이름입니다.

## MVP에 들어간 것

| 기능 | 내용 |
|---|---|
| 언어 | **라오어 ↔ 한국어**만. 화면 언어는 라오어(기본) / 한국어(운영자 확인용) |
| 계급 | 5계급: 아기(유치원·초등 저학년) → 꼬마(초등) → 청년(초등 고학년) → 대장(중학생) → 왕(고등학생) 코끼리 |
| 회차 | 1회차 = 50단어 = **5개씩 10묶음**. 18회차, **900단어** (1계급 100 · 2계급 200 · 3계급 200 · 4계급 200 · 5계급 200) |
| 단어 범위 | 숫자·인사·음식 → 기본 동사·형용사·의문사 → 학교·건강·돈·여행 → 사회·정치·경제·환경·과학·문화·마음 |
| 수준 테스트 | 처음 시작할 때 계급(1~5단계) 순서대로 단계별 6문제(5개 이상 맞히면 다음 단계, 2개 틀리면 그 계급 첫 회차부터 시작, 최대 30문제). '몰라요' 버튼으로 찍기 방지. 아는 회차는 통과 처리, 설정에서 다시 볼 수 있음. '한국어가 처음이에요'로 건너뛰기 가능 |
| 외우기 3단계 | **STEP 1 · 5개씩**: 5개 중 못 외운 단어만 반복, 5개를 다 외우면 다음 5개 → **STEP 2 · 25개씩**: 1~25, 26~50 → **STEP 3 · 50개씩**: 50개 전부. STEP마다 처음부터 다시 확인하며 외움 |
| 외우기 화면 | 위: 지금 묶음 단어(그림+한국어) 칩, 25·50개일 땐 옆으로 넘김 / 가운데: 뒤집히는 카드(앞: 그림·한국어·발음, 뒤: 라오어 뜻) / 아래: 「다시 볼래요」「외웠어요」. 버튼을 안 눌러도 자동으로 넘어감. 설정(초·방향·발음·섞기)은 ⚙️ 시트 |
| 4지선다는 나중에 | 처음엔 고르기·듣기·졸업시험이 **보이지 않음**. STEP 1·2·3을 모두 끝내면 열림 |
| 잠금 | 졸업시험 50문제를 **모두 맞혀야** 다음 회차가 열림. 계급의 모든 회차 통과 후 승급시험 30문제도 전부 맞혀야 다음 계급 |
| 초 조절 | 카드 넘김 1~10초, 한 바퀴마다 1초씩 빨라지기, 방향(한→라오 / 라오→한 / 섞어서) |
| 발음 | 기기 음성(TTS)으로 한국어 발음. 녹음 파일을 넣으면 녹음이 우선 재생 |
| 보상 | 월간 점수·랭킹 화면(예시 데이터), 커피 도장판(하루 1개, 10개=추첨권), 단어 스티커북(외운 단어가 색칠됨) |
| 디자인 | 파스텔 캔디 스타일 + 분홍 아기 코끼리 마스코트(SVG). 계급마다 리본·모자·학사모·별·왕관 |

## 폴더 구조

```
chang-korean/
├─ src/
│  ├─ data/words.ts      ← 계급·회차 구성 + 1~4회차 단어
│  ├─ data/rounds-more.ts ← 5~18회차 단어 (초등 고학년~고등학생)
│  ├─ i18n.ts            ← 화면 문구 (한·라오·태국어)
│  ├─ store.ts           ← 학습 기록·점수·도장·잠금 규칙 (기기 저장)
│  ├─ audio.ts           ← 발음(TTS/녹음 파일)·효과음
│  └─ screens/           ← 화면 (시작, 홈, 회차, 자동 반복 플레이어, 퀴즈, 보상, 설정)
├─ android/              ← 안드로이드 프로젝트 (Capacitor가 생성)
├─ scripts/              ← 단어 검사, 웹 한 파일 빌드, 아이콘 생성
└─ store/                ← 마스코트 원본(mascot.svg), 플레이스토어용 아이콘(icon-512.png)
```

## 실행 방법

```bash
cd chang-korean
npm install

npm run dev            # 웹 개발 서버 (http://localhost:5173)
npm test               # 단어 데이터 검사 (회차당 50개, 중복 없음)
npm run build:single   # 웹 버전 한 파일 → dist-web/index.html (글꼴 포함, 인터넷 없이도 동작)
```

### 웹 버전 (GitHub Pages)

main에 push하면 `.github/workflows/pages.yml` 이 웹 버전을 자동으로 올립니다.
주소: **https://fctj.github.io/chang-korean/**
(처음 한 번만 저장소 Settings → Pages → Source를 **GitHub Actions** 로 선택)

### 웹 버전을 다른 사람에게 공유하기

`dist-web/chang-korean.html` 은 외부 연결 없이 혼자 동작하는 파일입니다.

- **파일로 보내기**: 메신저·이메일로 보내면 받은 사람이 휴대폰/PC 브라우저로 엽니다.
- **링크로 공유하기**: `dist-web/` 폴더를 아무 정적 호스팅에 올리면 됩니다.
  - Netlify Drop(app.netlify.com/drop)에 폴더를 끌어다 놓기
  - 공개 GitHub 저장소에 `index.html` 을 올리고 Settings → Pages 켜기

### 안드로이드 APK

**방법 1. GitHub Actions (PC에 아무것도 설치하지 않아도 됨)**
push하면 `.github/workflows/android-apk.yml` 이 자동으로 APK를 만듭니다.
GitHub → Actions → *Chang Korean APK* → 최근 실행 → **Artifacts** 의 `chang-korean-debug-apk` 를 내려받아 폰에 설치하세요.
(처음 설치할 때 '출처를 알 수 없는 앱 설치 허용'이 필요합니다.)

**방법 2. Android Studio**
```bash
npm run android:sync   # 웹 빌드 + 안드로이드 프로젝트에 복사
npm run android:open   # Android Studio 열기 → ▶ 실행
```

## 단어 추가·수정

`src/data/words.ts` 에서 한 줄이 단어 하나입니다.

```ts
['사과', 'sagwa', 'ໝາກແອັບເປີ້ນ', 'แอปเปิ้ล', '🍎'],
//한국어  로마자    라오어            태국어      이모지
```

새 회차는 `makeRound(...)` 로 만들어 해당 계급의 `rounds` 에 넣으면 홈 화면에 자동으로 나타납니다.
수정 후 `npm test` 로 개수·중복을 검사하세요.

**녹음 파일 붙이기**: `public/audio/r1-01.mp3` 처럼 단어 id로 파일을 넣고 `AUDIO_READY` 에 id를 추가하면 TTS 대신 녹음이 재생됩니다.

## 서버를 붙일 때 바꿀 곳

- `store.ts` 의 `demoRanking()` → 서버 월간 랭킹 API로 교체 (지금은 **예시 데이터**이며 화면에도 '예시'라고 표시됨)
- `awardPractice / recordExam / recordPromo / completeSession` → 점수·도장을 서버에도 기록 (부정 방지 검증은 서버에서)
- 로그인(전화번호 인증) 추가 → 1인 1계정, 보상 발송용

## 알려진 한계

- **라오어 TTS**는 대부분의 기기에 없습니다. 한국어 발음은 정상, 라오어 소리는 녹음 파일로 해결 예정
- 태국어 번역(`th`)은 `words.ts` 에 데이터만 남아 있고 앱에는 나오지 않습니다
- 오래된 안드로이드(9 이하)에서는 일부 최신 이모지가 네모로 보일 수 있음 → 이모지 이미지 세트 번들링 검토
- 학습 기록은 기기 안에만 저장됨 (앱 삭제 시 사라짐). 서버 연동 후 해결
