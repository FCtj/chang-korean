# 포인트 제도

포인트는 **공부를 증명했을 때만** 쌓입니다. 카드를 넘기는 것만으로는 쌓이지 않습니다.
오래 공부하는 사람을 위해 하루 상한은 넉넉히(300P), 대신 **1시간 상한(60P)** 으로 비정상 속도를 걸러 냅니다.
규칙 값은 `src/store.ts` 위쪽 상수(`DAILY_CAP`, `EXAM_BONUS` …)에 모여 있습니다.

## 받는 법

| 하는 일 | 포인트 | 조건 |
|---|---|---|
| 단어 카드 「외웠어요」 · 묶음 다 보기 | 0P | 진도·공부한 날만 기록 |
| 연습 문제 정답 | +1P | 첫 번에 맞혀야 함 · 1초 넘게 생각한 답만 · 같은 단원은 하루 10P까지 |
| 오늘 공부 완료 | +5P | 문제 한 세트를 끝까지 풀면 · 하루 한 번 |
| 졸업시험 통과 (첫 번에 90% 이상) | +30P | 단원마다 처음 통과 한 번 · 외우기만으로는 단원 통과 안 됨 |
| 승급시험 통과 | +100P | 계급마다 처음 통과 한 번 |
| 국적 모의 평가 | 맞힌 수 × 1P | 60점 이상 · 하루 한 번 |
| 처음 실력 테스트 | 맞힌 수 × 10P | 처음 한 번 · 1초 안에 누른 답 제외 |
| 환영 선물 | 100P | 처음 한 번 |
| **하루 상한** | **300P** | 시험 보너스·환영 선물은 상한 밖 (한 번씩만) |
| **1시간 상한** | **60P** | 정상 속도로는 닿기 어려움 · 닿은 횟수는 의심 신호로 기록 |

## 치팅 막기

지금 앱에 있는 것
- 카드만 넘기면 0P
- 문제가 뜨고 1초 안에 누른 답은 포인트 없음 (진도·통계에는 반영)
- 틀린 뒤 다시 나온 문제는 포인트 없음
- 같은 단원 연습 문제는 하루 10P까지
- 시험 보너스는 처음 한 번만 · 1시간 상한 60P · 하루 상한 300P
- 의심 신호 기록(`state.signals`): 오늘 맞힌 수 · 그중 1초 안에 누른 수 · 1시간 상한에 닿은 횟수
- 보기·문제 순서는 매번 섞임 → 찍기(25%)로는 시험 통과 불가

교환소 열기 전에 서버에서 (할 일)
- 포인트 기록(`point_events`)을 서버가 다시 계산, 기기 숫자는 인정 안 함
- 하루·분당 기록 수 제한, 불가능한 속도 제외
- 계정 1개 = Facebook 1개, 한 기기 여러 계정 표시
- 교환 조건: 로그인 · 가입 14일 이상 · 공부한 날 10일 이상 · 1주 1번
- 큰 상품은 운영자 확인 후 발송, 이상 패턴(1시간 상한에 자주 닿음 · 빠른 답 비율 높음)은 검토 목록으로
- 랭킹·교환에는 서버가 확인한 포인트만 사용, 테스트 예시 데이터(`SAMPLE_DATA`)는 끔

## 정할 것

- 교환 가격 (제안: 커피 1,500P · 상품권 4,000P · 치킨 8,000P · 피자 10,000P — 하루 45P 꾸준히 하면 커피 한 잔에 약 한 달)
- 한 달 교환 예산 상한
- 교환 조건 값
- 예전에 카드 넘기기로 쌓인 포인트: 보여 주되 교환에는 서버 확인 포인트만 쓰는 안을 추천
