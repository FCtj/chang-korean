# Chang Korean 구상: 공부 기록 → 커뮤니티 → 일자리·유학 연결

> 한 줄: **"꾸준히 공부한 사람이 손해 보지 않게."**
> 앱이 학습자의 성실함과 실력을 믿을 수 있는 기록으로 남기고, 본인이 원할 때 그 기록으로
> 라오스의 한국 식당 아르바이트 · 한국 유학 · 한국 일자리 기회에 연결한다.

## 1. 무엇을 모으나 (학습 데이터)

| 묶음 | 항목 | 지금 상태 |
|---|---|---|
| 꾸준함 | 공부한 날 수, 연속 공부, 최근 30일 성실도(공부한 날 ÷ 30), 접속 시간대 | ✅ 공부한 날·연속·성실도 (v0.11) |
| 실력 | 외운 단어 수, 통과한 회차·계급, 시험 점수(최고·첫 시도), 틀린 단어 복습률 | ✅ (서버 검증은 시험·승급만) |
| 성과 | 월간·주간 랭킹 순위, 1등 기록, 받은 보상 | ✅ 랭킹 / 보상 기록은 예정 |
| 목적 | 배우는 이유(일·여행·학교·K-POP·가족) | ✅ |
| 커뮤니티 | 그룹 활동, 받은 응원(반응) 수, 다른 사람 응원 수 | ✅ 그룹·반응 (v0.11) |

**믿을 수 있는 기록** 이어야 연결이 됩니다.
- 점수는 서버 규칙(`award_points`)으로만 쌓임: 하루 상한, 보너스 1회.
- 시험·승급 통과는 서버가 자동으로 **'인증' 글** 을 올림. 직접 써서 올릴 수 없음.
- 다음 단계: 시험에 시간 제한·문제 섞기, 이상한 패턴(1초에 50개 등) 감지. 연결 직전에는 **확인 시험** (파트너 매장·어학원에서 오프라인, 또는 영상).

## 2. 나의 한국어 이력 (Learning Passport)

- 커뮤니티 탭 맨 위 카드 (v0.11): 공부한 날 · 연속 · 외운 단어 · 통과한 회차 · 최고 시험 · 30일 성실도
- 다음: **공유 링크 / QR**
  - 본인이 버튼을 눌러야 만들어짐. 기한(예: 14일), 언제든 끊기.
  - 받는 쪽은 요약만 봄: 이름·사진·레벨·성실도·인증 시험. 틀린 단어 같은 세부는 안 보임.
  - 한국어·라오어·태국어로 볼 수 있음. PDF 저장.
- 그다음: 'TOPIK / EPS-TOPIK 예상 수준'. 실제 시험이 아니라는 표시를 분명히.

## 3. 커뮤니티 (v0.11에서 시작)

- **그룹**: 친구·반·직장·식당 동료끼리. 초대 코드 6자리, 최대 50명, 한 사람 최대 20개 그룹.
- **그룹 랭킹**: 이번 주 / 이번 달.
- **자랑하기**: 내 실제 기록으로 만든 문장(외운 단어 N개, N일 연속, 이번 달 N점, N계급) + 한마디.
  - 문장은 데이터로 저장돼서, 보는 사람마다 **자기 언어로** 보임 (라오·태국·베트남·한국어).
- **인증 글**: 졸업시험·승급시험 통과는 자동으로 내 그룹들에 올라감 (노란 테두리 + ✓ 인증).
- **반응**: 👏 🔥 💪 ❤️ 😂
- 결과 화면(STEP 완료·단어팩 완료)에서 **'그룹에 자랑하기'** 한 번에.
- 다음 후보
  - 그룹 미션: "이번 주 그룹 전체 2,000점", 달성하면 그룹 보상.
  - 1:1 응원 / 짝꿍 공부.
  - 선생님·사장님 계정: 그룹원 진도를 한눈에 (본인 동의한 범위만).
  - 신고·차단, 글 숨기기 (공개 그룹을 열기 전에 꼭 필요).

## 4. 연결 (단계별)

| 단계 | 연결 | 상대 | 앱이 하는 일 |
|---|---|---|---|
| ① 지금 가능 | **라오스 한국 식당·카페·K-마트 아르바이트** | 비엔티안의 한국 사장님 | 사장님이 '한국어 되는 직원' 공고 → 학습자가 이력 링크로 지원 |
| ② | **한국어 학원·대학 어학당** | 라오스 한국어 교육기관, 한국 대학 국제처 | 장학·입학 상담 연결. 앱 성실도를 장학 참고자료로 |
| ③ | **한국 유학** (어학연수 D-4, 학부 D-2, 정부초청장학 GKS) | 대학, 공인 유학원 | 이력 + 서류 체크리스트 + 인터뷰 한국어 팩 |
| ④ | **한국 일자리 (고용허가제 EPS)** | **공식 경로만**: 라오스 노동사회복지부 · EPS 센터, 한국산업인력공단 | EPS-TOPIK 대비 단어팩·모의시험, 공식 접수 일정 안내. **앱이 직접 알선하지 않음** |

⚠️ **고용허가제는 정부 대 정부 제도** 입니다. 라오스도 송출국이고, 라오스 EPS 센터가 EPS-TOPIK을 시행합니다. 2026년 8월에는 라오스 정부가 "더 빨리 보내 준다"는 무허가 브로커를 조심하라고 경고했습니다.
그래서 앱은 **공부 + 공식 정보 안내** 까지만 하고, 직업 소개·알선은 허가받은 기관과만 연결합니다.
라오스·태국에서 유료 직업소개를 하려면 허가가 필요할 수 있으니, 시작 전에 현지 법률 확인이 필요합니다.

## 5. 개인정보·동의 원칙 (연결 사업의 신뢰 기반)

1. **내 기록은 내 것.** 기업·학교에는 본인이 공유 버튼을 누를 때만, 고른 항목만.
2. **목적별 따로 동의:** 랭킹 공개 / 그룹 공유 / 일자리 연결 / 유학 연결을 각각 켜고 끄기.
3. **미성년자(만 18세 미만)는 일자리 연결 불가.** 유학 연결은 보호자 동의.
4. **언제든 삭제:** '서버 기록 지우기'가 이미 있음 (v0.7). 그룹 글·반응도 함께 지움 (v0.11).
5. 라오스 「전자정보보호법」, 태국 PDPA, 한국 개인정보보호법을 기준으로 약관·개인정보처리방침 작성 (출시 전 법률 검토).
6. 사진·이름은 공개 범위를 본인이 정함 (랭킹에 이니셜만 등).

## 6. 돈은 어떻게 (지속 가능하게)

- 학습자는 **무료**. 랭킹 보상(커피 쿠폰 등)은 파트너가 후원.
- 파트너(식당·학원·대학·유학원):
  - 공고 등록 / 인증된 지원자 열람 = 유료 (B2B)
  - 브랜드 단어팩 후원 ("○○식당 메뉴 한국어")
- 나중에: 프리미엄(오프라인 확인 시험, 인터뷰 연습, 1:1 첨삭).

## 7. 다음 개발 순서 (제안)

1. 서버 켜기: Supabase 프로젝트 + 페이스북 앱 (`docs/backend-setup.md`)
2. 커뮤니티 신고·차단 + 그룹 관리자 기능
3. 이력 공유 링크 / QR (읽기 전용 페이지, 기한·철회)
4. 파트너 1곳(비엔티안 한국 식당)과 시범: 아르바이트 공고 → 이력 링크로 지원
5. EPS-TOPIK 대비 팩 + 모의시험
6. 약관·개인정보처리방침·동의 화면 (출시 전 필수)
