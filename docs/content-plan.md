## 품질: 초안 → 자동 검사 → 원어민 검수

1. 초안: 주제 목록에 맞춰 단어·문장·발음·이모지·라오/태국/베트남어 뜻 (교재 내용을 그대로 옮기지 않음)
2. 자동 검사: `npm test`
3. **원어민 검수**: 앱 **설정 → 🔍 번역 검수 도와주기** (Facebook 로그인 필요)
   - 언어(라오·태국·베트남)와 단원을 고르고, 항목마다 **✅ 맞아요 / ✏️ 고칠게요 / 건너뛰기**
   - 결과는 Supabase `translation_reviews` (본인 것만 보임)
4. 운영자가 결과 보기 — Supabase **SQL Editor** 에서:

```sql
-- 고쳐 달라는 의견 (많은 순)
select unit_id, ko, lang, current_text, suggestion, count(*) as n
from translation_reviews
where verdict = 'fix'
group by 1, 2, 3, 4, 5
order by n desc, unit_id, ko;

-- 단원·언어별 검수 진행 (맞아요/고칠게요 수)
select unit_id, lang,
       count(*) filter (where verdict = 'ok')  as ok,
       count(*) filter (where verdict = 'fix') as fix
from translation_reviews
group by 1, 2
order by 1, 2;
```

5. 고칠 내용을 정리해서 원본 파일에 반영 → 배포
