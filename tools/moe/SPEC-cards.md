# 교육부 기본 어휘 — 빠진 단어 카드 만들기 (한국 학생용 단어 앱)

한국인이 영어·일본어를 배우는 앱입니다. 입력 단어는 **교육부 2022 개정 교육과정 기본 어휘 목록**(영어 3,000 · 일본어 기본 어휘표)에 있는데 앱에 아직 카드가 없는 말입니다. 중·고등학생 수준으로, 자연스럽고 쉬운 예문을 써 주세요.

## 영어 (`en-in-N.json` → `en-out-N.json`)
입력: `[{ "w": "acid", "mark": "", "forms": [], "hint": "noun B1" }, ...]` — `mark` 는 `*` 초등 · `**` 중·고 공통 · `''` 고교 선택. `hint` 는 CEFR-J 품사·수준(없을 수 있음).
출력 (입력의 모든 단어를 키로):
```json
{ "acid": { "mean": "[명] 산 · [형] 신맛의", "emoji": "🧪", "ex": "Lemon juice contains a lot of acid.", "exKo": "레몬즙에는 산이 많이 들어 있어요." } }
```
- `mean`: '[품사] 한국어 뜻' — 품사: 명 동 형 부 전 접 대 감 조 (두 품사면 `[동·명]` 처럼). 뜻 1~3개, 짧게.
- `ex`: 대문자로 시작해 `.` `?` `!` 로 끝나는 짧은 문장 (110자 이하), 단어(또는 그 변화형)를 포함.
- `exKo`: 자연스러운 한국어 번역 (해요체).
- `emoji`: 하나, **Emoji 13 이하** (🫠🪪🟰🛟🫡🫶 같은 Emoji 14 이후 금지).
- 정말 카드로 만들 수 없는 말만 `{ "skip": true }`.

## 일본어 (`ja-in-1.json` → `ja-out-1.json`)
입력: `[{ "term": "温泉", "kana": "おんせん", "kanji": "温泉" }, ...]`
출력 (입력의 `term` 을 키로):
```json
{ "温泉": { "mean": "온천", "emoji": "♨️", "ex": "週末に家族で温泉に行きました。", "rom": "しゅうまつにかぞくでおんせんにいきました。", "exKo": "주말에 가족이랑 온천에 갔어요." } }
```
- `mean`: 한국어 뜻 (1~3개, 쉼표로, 가나 금지).
- `ex`: 짧은 일본어 문장 (45자 이하, 。？！ 로 끝), 단어 포함. `rom`: ex 전체의 히라가나 읽기 (한자 없이, 가타카나 말은 가타카나 그대로).
- `emoji`, `exKo`: 영어와 같음. 입력에 이상한 항목(감탄사 조각 `おー` `ごー`, 잘못 읽힌 한자 등)은 `{ "skip": true }`.
