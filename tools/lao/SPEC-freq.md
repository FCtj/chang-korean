# 라오스어판 "자주 쓰는 말" — 단어 카드 만들기

한국인이 라오스어를 배우는 앱의 단어 카드입니다. 입력 파일의 라오어 단어들은 라오어 말뭉치(HVULao_NLP, 11,000문장)에서 자주 나오는 순서대로 뽑았고, 모두 라오스 정부 라오어-영어 사전에 있는 말입니다.

## 입력 (`in-N.json`)
```json
[{ "w": "ແລະ", "rank": 3, "gloss": ["and", "look at", ...], "ctx": ["말뭉치 문장", "말뭉치 문장"] }, ...]
```
- `gloss`: 사전의 영어 뜻 (여러 개). **사전에 오류가 많습니다** (예: ບໍ່ 을 "source" 라고만 적었지만 가장 흔한 뜻은 부정 "안/못", ຂອງ 을 "the Mekong river" 라고 적었지만 흔한 뜻은 "~의 / 물건"). 영어 뜻을 그대로 옮기지 말고, `ctx` 문장과 라오어 지식으로 **현대 라오어(비엔티안)에서 가장 흔하게 쓰는 뜻**을 고르세요.
- `ctx`: 그 단어가 실제로 쓰인 말뭉치 문장 (띄어쓰기 없음).

## 출력 (`out-N.json`) — 입력의 모든 단어를 키로
```json
{
  "ແລະ": { "mean": "[접] 그리고, ~와", "emoji": "➕", "ex": "ຂ້ອຍກິນເຂົ້າແລະດື່ມນ້ຳ.", "exKo": "저는 밥을 먹고 물을 마셔요." },
  "ບໍ່": { "mean": "[부] 안, 못 (부정)", "emoji": "🚫", "ex": "ຂ້ອຍບໍ່ຮູ້.", "exKo": "저는 몰라요." },
  "XXXX": { "skip": true }
}
```
- `mean`: **'[품사] 한국어 뜻'** — 품사: 명 · 동 · 형 · 부 · 대(대명사) · 수(수사) · 접(접속사) · 전(전치사) · 조(조사·문말 어기사) · 감(감탄사) · 분(분류사) · 관(관형사). 뜻은 짧게 1~3개, 쉼표로. 영어 금지. 문법 단어는 쓰임을 괄호로 짧게 (예: `[조] ~했다 (과거·완료)`).
- `emoji`: 그림 하나. **Emoji 13 이하**만 (🫠🫥🪪🟰🛟🪫🫡🫶🫴 같은 Emoji 14 이후 금지). 문법 단어는 기호 그림 (➕ 🚫 ❓ ⏩ 📍 🔁 등). 이 파일 안에서 되도록 겹치지 않게.
- `ex`: **짧고 쉬운 일상 라오어 문장** (45자 이하), 그 단어를 **입력의 철자 그대로** 포함. 신문체 말고 생활 회화체. 끝에 `.` 또는 `?`.
- `exKo`: ex 의 자연스러운 한국어 번역 (해요체, `.` `?` `!` 로 끝).
- `skip: true`: 사람 이름 · 지명(나라 이름 ລາວ/ໄທ/ຫວຽດນາມ 같은 흔한 것은 넣어도 됨) · 약어 · 단어 조각(혼자 쓰지 않는 음절) · 뜻이 불분명한 것.
